是：系词与定义

быть无对

是；有；在

  • 支кем? чем?（过去、将来时身份多用五格）· у кого́?（有）
  • 搭У меня есть время; был студентом
  • ⚠现在时“是”一般省略（Он — аспирант）；过去时说身份常用五格：был аспирантом

В 2020 году он был аспирантом МГУ.2020 年他是莫斯科大学的博士生。

явля́ться按义项体对应

是（书面）；（явиться）到场

  • 支кем? чем?（五格）
  • 搭является ключевым фактором
  • ⚠“是”义无体对；不要加 как
  • 学X является одним из ключевых факторов

Этот метод является наиболее точным.这种方法是最精确的。

представля́ть собо́й无对

是、构成（书面，描述“是什么样的东西”）

  • 支что?（四格）
  • 搭представлять собой исследование / систему
  • ⚠接四格：✗ представляет собой исследованием
  • 学X представляет собой…

Диссертация представляет собой комплексное исследование городской среды.本论文是一项关于城市环境的综合研究。

служи́ть / послужи́ть按义项体对应表外补充

充当、作为；服务

  • 支чем?（五格）· для чего́?
  • 搭служить основой / примером / доказательством
  • 学служить основой для…

Эти данные служат основой для дальнейшего анализа.这些数据是进一步分析的基础。

счита́ться无对表外补充

被认为是

  • 支кем? чем?（五格）· , что…
  • 搭считается ведущим специалистом; считается, что…
  • 学Считается, что…

Этот подход считается классическим.这种方法被认为是经典的。

Существует несколько подходов к решению этой задачи.解决这个问题有几种方法。

Имеются данные о том, что эффект временный.有数据表明该效应是暂时的。

встреча́ться按义项体对应
