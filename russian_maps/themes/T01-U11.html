正面评价

хвали́ть / похвали́ть严格体对应表外补充

表扬

  • 支кого́? за что?
  • 搭похвалить за работу
  • 派похвала́

Руководитель похвалил меня за вторую главу.导师表扬了我的第二章。

одобря́ть / одо́брить严格体对应表外补充

赞同；批准

  • 支что?
  • 搭одобрить план / тему
  • 派одобре́ние

Тема диссертации одобрена на заседании кафедры.论文题目在教研室会议上获批。

цени́ть / оцени́ть按义项体对应表外补充

重视、珍视；（оценить）评价、评估

  • 支что? кого́?
  • 搭высоко ценить; оценить по достоинству
  • 派це́нность, оце́нка

Я ценю ваше мнение.我很重视您的意见。

批评与责备

критикова́ть无对表外补充

批评

  • 支кого́? что? за что?
  • 搭критиковать за неточность
  • 派кри́тика, кри́тик, крити́ческий
  • 学критический анализ литературы

Оппонент критиковал выбор выборки.评阅人批评了样本的选择。

де́лать / сде́лать замеча́ние严格体对应

提意见；批评

  • 支кому́? · по поводу чего́?
  • 搭сделать замечание по оформлению
  • ⚠答辩里 замечание = 意见、批评

Оппонент сделал несколько замечаний по оформлению.评阅人对格式提了几点意见。

руга́ть / отруга́ть严格体对应简写

骂、训斥

  • 支кого́? за что?
упрека́ть / упрекну́ть一次（-нуть）表外补充

责备

  • 支кого́? в чём?
  • 搭упрекать в небрежности
  • 派упрёк
  • ⚠常用 в + 六格

Его упрекали в небрежности.人们责备他马虎。

осужда́ть / осуди́ть严格体对应表外补充

谴责；判刑

  • 支кого́? что? за что?
  • 搭осудить насилие
  • 派осужде́ние
  • ⚠形近 обсуждать（讨论）

Мировое сообщество осудило нападение.国际社会谴责了这次袭击。

抱怨与投诉

жа́ловаться / пожа́ловаться严格体对应

抱怨；投诉

  • 支на кого́? на что? · кому́?
  • 搭жаловаться на шум
  • 派жа́лоба（投诉）
  • ⚠用 на：✗ жаловаться о…

Соседи пожаловались на шум.邻居投诉了噪音。

玩笑与不真实

шути́ть / пошути́ть严格体对应

开玩笑

  • 支над кем? · с кем?
  • 派шу́тка
  • ⚠шутить над кем = 取笑；шутить с кем = 和……开玩笑

Не обижайся, я пошутил.别生气，我开玩笑的。

врать / совра́ть严格体对应简写

撒谎（口语）

  • 支кому́? о чём?
лгать / солга́ть严格体对应表外补充

撒谎（较书面）

  • 支кому́?
обма́нывать / обману́ть严格体对应简写

欺骗

  • 支кого́?
издева́ться无对表外补充

嘲弄

  • 支над кем?
